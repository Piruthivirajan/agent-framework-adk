What this page does

Connect an MCP server and its tools become available to the assistant at the next message, without a restart. When the reference documents have no answer, the assistant tries these tools.

Supported: MCP servers reachable over the network with Streamable HTTP (current) or the older SSE transport. Not supported: stdio servers (started as a local command), because a hosted application cannot run commands for you.
Credentials: kept in the memory of the running application only, shown here by header name only, never written to disk or to the log, and never sent to the language model. They are lost when the application restarts.
